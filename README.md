# kozuemi（梢見）

コミットグラフを中心に据えた git TUI。ブランチやワークツリーの先端（梢）を一望し、全体の中の現在地を見失わずに切り替え・比較・操作できる。

グラフは常に全 ref (`--all`) を日付順で描画し、HEAD を起点にしない。ブランチのチェックアウトやワークツリーの切り替えでは HEAD マーカー（緑の `●`）が移動するだけで、グラフの並びとスクロール位置は変わらない。

## インストール

```sh
go install github.com/TAATHub/kozuemi@latest
```

ソースからビルドする場合は clone したディレクトリで `go install .` を実行する。

```sh
git clone https://github.com/TAATHub/kozuemi.git
cd kozuemi
go install .
```

どちらも `$(go env GOPATH)/bin`（既定 ~/go/bin）に入る。更新も同じコマンドで行う（clone した場合は `git pull` してから `go install .`）。

## 使い方

```sh
kozuemi [--max N] [--cwd-file PATH] [repo-dir]
```

- `--max`: グラフに読み込む最大コミット数 (既定 5000, 0 で無制限)
- `--cwd-file`: 終了時にアクティブなワークツリーのパスを書き出す

TUI から親シェルのカレントディレクトリは変えられないため、ワークツリー切り替え後にそのディレクトリへ移動したい場合は次のようなラッパーを使う。

```zsh
kz() {
  local f=$(mktemp)
  kozuemi --cwd-file "$f" "$@"
  local d=$(<"$f"); rm -f "$f"
  [[ -n $d && $d != $PWD ]] && cd "$d"
}
```

## 配色

文字色は ANSI パレット（0〜15 番）で指定するので、端末のテーマがそのまま反映される。

選択行・差分の追加/削除行などの背景色は、Ghostty の設定（`~/.config/ghostty/config`、`~/Library/Application Support/com.mitchellh.ghostty/config`、`config-file` で読み込まれるファイル）とそこで指定された `theme` を読み、テーマの `background` にパレット色を混ぜて作る。選択行は `selection-background` を使う。`theme = light:A,dark:B` は macOS の外観モードで選ぶ。Ghostty の設定が見つからない場合は組み込みの暗色系の背景色を使う。

## 画面

lazygit と同じパネル構成・キー操作。

- `[1] Worktrees` / `[2] Local - Remotes - Tags`（左カラム上部。幅は画面の 22% で固定。Local は名前の右に upstream との関係を表示: `✓` 同期済み、`↑1↓2` 先行・遅れ、`✗ gone` リモートで削除済み、`local` upstream なし。タブはクリックでも切り替え可）
- `[3] Commits`（右上）: 左パネルで項目を選ぶと、グラフのカーソルがその ref のコミットへ移動する（並び順は変わらない）。選択中の ref とその HEAD に含まれないコミットに `┃` が付き、ラベルが太字で強調される。HEAD の上に未コミット変更の行 `◌` が出る（差分には未追跡ファイルも含む）
- `[4] Commit`（左下）: コミット情報（ハッシュ・作者・日付・ref・変更ファイル・メッセージ）。スクロール可
- `[5] Diff`（右下）: Commit のファイルツリーで選択中のファイルだけを side-by-side（`v` で unified に切替）で表示する。コミットを切り替えると先頭のファイルが選ばれる。Commit では `j`/`k`・クリックでファイルを選び、ホイール・`,`/`.` はスクロールのみ（選択は変わらない）。Diff の `]`/`[` で前後のファイルへ
- ヘッダー: 現在のワークツリー・ブランチ・ahead/behind・未コミット変更数・rebase 等の進行状態・diff モード

グラフは `git log --graph` の ASCII ではなく、親子関係から独自にレーンを割り当てて罫線で描く（[keifu](https://github.com/trasta298/keifu) 風）。1 コミット 1 行で、マージは `●─╮`、分岐したブランチの合流点は `├─┴─╯` の接続行で表す。レーンごとに色が決まり、ノードとラベルも同じ色になる。

各行は `ノード  ラベル 件名 … 作者  ハッシュ  日時`。ラベルは背景色付きのバッジで、現在のブランチは ` ✓ main `（緑）、他のブランチはレーン色、upstream と同じコミットなら ` main ↔ origin ` とまとめ、upstream がリモートで削除済みなら ` main ✗ ` と表示する。タグは黄色、他ワークツリーはマゼンタ。幅が足りないときは日時→ハッシュの順に省く。

記号: `●` HEAD（緑）・他ワークツリーの HEAD（マゼンタ）/ `○` コミット / `◉` マージコミット / `◌` 未コミット変更 / `▌` 選択行 / `┃` 左パネルで選んだ ref の範囲。他ワークツリーは `ブランチ名 (ワークツリー名)` と表記

## キー

全キーはアプリ内の `?` で確認できる。

### 共通

| キー | 動作 |
|---|---|
| `h` `l` `←` `→` `tab` / `1`〜`5` | パネル移動 / 直接フォーカス |
| `j` `k` / `,` `.` / `<` `>` | 移動 / ページ / 先頭・末尾 |
| `/` `n` `N` | 検索（入力のたびに反映）/ 次 / 前。`[2]` では一覧の絞り込みになり、esc で解除 |
| `R` | リフレッシュ（別ペインでのコミット・fetch・ファイル編集などは、kozuemi にフォーカスが戻った時に自動で反映。tmux では `set -g focus-events on` が必要） |
| `P` `p` | push（upstream 未設定なら `--set-upstream`、rejected 時は force-with-lease を確認）/ pull |
| `m` | merge・rebase・cherry-pick の continue / abort / skip |
| `S` | stash メニュー |
| `:` | シェルコマンド実行 |
| `W` `ctrl+e` | diff モード（選択中を基点にマーク → 別の項目を選ぶとその差分） |
| `+` `_` | フォーカス中のペインを最大化（zoom）/ 戻す。最大化中にフォーカスを移すと最大化対象も切り替わる |
| `J` `K` `ctrl+d` `ctrl+u` / `H` `L` | 差分パネルの縦 / 横スクロール |
| `{` `}` / `ctrl+w` / `v` | 差分のコンテキスト行数 / 空白無視 / side-by-side と unified の切替 |
| `@` | グラフで HEAD へジャンプ（独自） |
| `esc` | 検索解除 → diff モード解除 → 最大化解除 |

### Commits `[3]`

| キー | 動作 |
|---|---|
| `enter` | 差分パネルへフォーカス |
| `space` | チェックアウト（そのコミットのブランチ、無ければ detached） |
| `s` `f` `r` `d` `e` | squash / fixup / reword / drop / edit（HEAD 祖先のコミットのみ。`--autostash` 付き rebase で実行） |
| `i` | そのコミットから interactive rebase |
| `c` `V` `ctrl+r` | cherry-pick 用にコピー / 貼り付け / クリア |
| `t` `T` `g` `M` | revert / tag / reset メニュー / merge |
| `n` `w` | 新規ブランチ / 新規ワークツリー |
| `ctrl+o` | ハッシュをコピー |
| `d` / `s`（未コミット変更の行） | 変更の破棄メニュー（すべて / 追跡ファイルのみ / 未追跡ファイルのみ）/ stash |

### Branches `[2]`（`[` `]` でタブ切替）

| キー | 動作 |
|---|---|
| `space` / `enter` | チェックアウト / グラフ上の位置へ |
| `n` `w` `c` `-` | 新規ブランチ / 新規ワークツリー / 名前でチェックアウト / 直前のブランチ |
| `d` | 削除メニュー（ローカル・リモート） |
| `r` `M` `g` | 現在のブランチをこのブランチへ rebase / merge / reset メニュー |
| `f` | fast-forward（Remotes タブでは fetch） |
| `R` `T` `P` | rename / tag 作成 / tag の push（Tags タブ） |

### Worktrees `[1]`

| キー | 動作 |
|---|---|
| `space` `enter` | 切り替え |
| `n` `d` `f` | 新規 / 削除 / fetch --all |

### Commit `[4]` / Diff `[5]`

Commit では `v`（もう一度 `v` か `esc` で解除）または `shift+↑↓` でファイルを範囲選択でき、Diff には選択した全ファイルを並べて表示する。未コミット変更を表示中の Commit では、ファイルの状態を `git status` と同じ 2 桁（左: index＝緑、右: ワークツリー＝赤）で表示し、`space` で選択中のファイルをステージ / 解除（すべてステージ済みなら解除）、`a` ですべてステージ（すべてステージ済みなら全解除）、`c` でステージ済みの変更をコミット、`d` で選択中のファイルの変更を破棄する（未追跡ファイルは削除）。ステージ・解除の後はファイルの状態だけを読み直す。長い行は折り返して表示する（Diff の `w` で折り返しを切り、`H` `L` の横スクロールに切り替え）。`]` `[` で前後のファイルへ切り替え、`t` で diff モード中の `A..B`（ツリー差分）と `A...B`（merge-base 以降の B 側の変更）を切り替え。

ワークツリーの追加先は `<メインワークツリー>-<ブランチ名>`（スラッシュはハイフンに置換）。
